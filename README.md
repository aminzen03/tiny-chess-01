A 4 KB chess engine in pure Python: alpha-beta search with quiescence, tapered piece-square evaluation, MVV-LVA/killer/history move ordering and an opening book, packed with LZMA into a single 4,095-byte main.py. It plays through the make.fun env at a fixed 100,000 nodes per move and rates ~1,365 Elo on the practice gauntlet (floor 1,154).

## Run it

```sh
python3 main.py
```
